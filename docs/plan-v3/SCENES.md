# 차시별 장면 구성안 — 수업 내용을 풀어 쓴 대본의 뼈대

[PLAN-v3.md](../../PLAN-v3.md) 5장의 부록이다. 차시마다 **무엇을 어떤 순서로, 한 화면에 하나씩** 보여 줄지를 적었다.
개발할 때 이 표의 한 줄이 수업 화면의 장면 하나가 되고, 장면마다 교사 노트(설명 · 발문 · 예상 답 · 시간)가 붙는다.

- 숫자는 모두 지금 사이트의 예제 데이터로 검산한 값이다(개발 때는 계산 결과에서 자동으로 가져온다).
- **구분** — 도입 / 개념 / 전개 / 깊이 / 정리. `✏️` = 학생이 활동지에 쓰는 장면, `✋` = 멈춤 질문(답은 다음 클릭), `◇` = 4차시로 줄일 때 건너뛰는 장면.
- **화면의 주인공** — 그 장면에서 크게 보이는 것 하나(데이터가 옮겨 가는 장면만 둘).
- **한 번 누를 때 바뀌는 것** — 장면 안에서 →를 한 번 누를 때마다 일어나는 변화. 쉼표로 나눈 것은 클릭을 따로 한다.

## 3차시 · 선형회귀 ① — 직선 · 예측 · 오차 · 손실 (50분, 33장면)

## 선택 · 준비 차시 — 데이터와 자료구조 (25~50분, 약 30장면)

네 알고리즘에 들어가기 전에 "상자 그림"으로 자료구조를 익힌다. 4차시 편성에서는 차시마다 있는 "오늘 쓸 자료구조" 장면이 이것을 대신한다.

| 묶음 | 장면 수 | 화면의 주인공 | 바뀌는 것 |
|---|---|---|---|
| 머신러닝이 푸는 문제 셋 (분류 · 회귀 · 군집) | 3 | 예 그림 하나씩 | 문제마다 "무엇을 맞히나" |
| 정답이 있는가 (지도 · 비지도) | 1 | 표 둘 | 레이블 칸이 있다 / 없다 |
| 데이터는 표 (줄 = 샘플, 칸 = 특징, 레이블) | 2 | 표 | 줄 강조, 칸 강조 |
| 표 = 리스트의 리스트 | 2 | 표 | 한 줄 꺼내기, 한 칸 꺼내기 |
| 리스트 — 번호 · 뒤에 추가 · 정렬 · 앞에서 k개 | 5 | 리스트 | 한 칸씩 |
| 딕셔너리 — 키 : 값 · 세기 · 가장 큰 값의 키 | 4 | 딕셔너리 | 새 키, +1 |
| 변수 — 값 하나, 새 값이 옛 값을 지운다 · 기록 리스트 | 3 | 변수 상자 · 리스트 | 0 → 0.5, 기록 한 칸 |
| 리스트의 리스트(묶음)와 평균 | 3 | 묶음 | 넣기, 평균 |
| 스택 — 쌓기 · 내리기 | 3 | 스택 | 쌓임, 빠짐 |
| 네 알고리즘 × 자료구조 지도 | 1 | 표(4줄) | 한 줄씩 |
| 확인 문제 | 3 | 문제 + 보기 | 정답 · 풀이 |

지금의 📦 자료구조 도구 6개(손으로 조작하는 실습)는 **연습** 메뉴에 그대로 두고, 이 차시의 해당 장면에서 "실습 열기"로 연결한다.

## 선택 · 종합 차시 — 네 알고리즘 정리와 모의시험 (50분, 약 25장면)

| 묶음 | 장면 수 | 화면의 주인공 |
|---|---|---|
| 네 알고리즘 한눈에 (비교표를 한 줄씩) | 5 | 표 |
| 자료구조별로 다시 보기 (리스트 · 딕셔너리 · 변수 · 스택이 쓰인 장면) | 4 | 자료구조 하나씩 |
| 섞어 풀기 — 종합 모의시험 8문제 (한 문제에 한 화면, 정답 · 풀이 · 그 장면 다시 보기) | 8 × 2 | 문제 + 보기 |
| 시험 안내 (형식 · 준비 방법) | 1 | 문장 |
