# 교사용 안내 — 자료구조로 다시 보는 머신러닝

학생들이 **k-최근접 이웃 · k-평균 · 선형회귀 · 의사결정트리**를 이미 한 번 배운 뒤,
"공식"이 아니라 **"데이터가 어떤 자료구조로 옮겨 가는가"**로 다시 따라가며 **기말고사를 준비**하는 사이트입니다.
설치·로그인 없이 주소 하나로 접속합니다.

> 사이트 주소: `https://yanghyeokjin33.github.io/Fundamentals-of-AI/`

## 1. 화면 구조

| 큰 탭 | 쪽 | 무엇을 |
|---|---|---|
| **📦 자료구조 도구** | 7쪽 | 안내 + 도구 6개를 손으로 조작 (첫 화면) |
| **🤖 알고리즘** | 4 × 5~6쪽 | `[k-최근접 이웃] [k-평균 군집] [선형회귀] [의사결정트리]` 하위 탭 |
| **✅ 정리·확인** | 3쪽 | 한 장 정리표 · 종합 모의시험 · 개념 확인 |

### 📦 도구 쪽 — "무엇을 하고, 무엇을 배우나"가 쪽마다 보인다

1. **🎯 미션** — 할 일이 순서대로 적혀 있고, 지금 눌러야 할 단추가 깜빡입니다. 단계마다 "무엇을 보면 되는지"가 함께 나옵니다.
2. **🎓 배운 것** — 미션을 마치면 그 도구에서 기억할 2~3줄이 열립니다.
3. **🔗 알고리즘 속에서는** — 그 도구가 어느 알고리즘의 몇 번째 의사코드 줄에서 어떻게 쓰이는지 카드로 보여 주고, **그 장면 보러 가기**를 누르면 알고리즘 화면의 바로 그 장면으로 이동합니다.

| 도구 쪽 | 쓰이는 곳 |
|---|---|
| 표 = 리스트의 리스트 | 네 알고리즘의 입력 |
| 거리 재기 (d²) | k-NN 3줄, k-평균 5줄 |
| 정렬하고 앞에서 k개 | k-NN 5~6줄, 의사결정트리 7줄(가장 작은 점수 고르기) |
| 딕셔너리로 세기 | k-NN 7~9줄, 의사결정트리 점수표(2·6줄) |
| 묶음으로 나누고 평균 내기 | k-평균 3·6·7줄, 의사결정트리 나누기(5줄) |
| 조금씩 고쳐 가기 — 갱신과 기록 | 선형회귀 7~8줄, k-평균 중심 교체(8~9줄) |

### 🤖 알고리즘 쪽 — 한 쪽에 한 단계만

| 쪽 | 무엇을 |
|---|---|
| **문제 보기** | 무엇을 묻는 문제인지, 입력·출력, 시험에서 자주 묻는 것 |
| **단계 쪽 (2~3개)** | 의사코드 일부만 다룬다. 이 쪽의 줄만 진하게, 이 단계에서 바뀌는 자료구조 상자만 보인다. ⏭로 한 줄씩 |
| **📝 추적표로 정리** | 시험 답안 모양의 표. **?** 칸을 손으로 채운 뒤 눌러서 확인. 조건을 바꾸면 표가 다시 계산된다 |
| **🎯 시험 대비 연습** | 객관식 5문제, 한 번에 한 문제. 채점 → 풀이 → **🔎 그 장면 보기**. **🎲 새 문제**를 누르면 조건(k · 질문점 · 시작 중심 · 학습률 · 기준)이 바뀐 새 세트 |

단계 쪽 구성:

| 알고리즘 | 단계 쪽 |
|---|---|
| k-NN | ① 거리 재기(1~4줄) · ② 정렬하고 k개 고르기(5~6줄) · ③ 투표하기(7~9줄) |
| k-평균 | ① 1회차 할당 · ② 1회차 갱신·수렴 판정 · ③ 반복해서 수렴까지 |
| 선형회귀 | ① 예측과 오차 · ② 손실과 기울기 · ③ 갱신하고 반복하기 |
| 의사결정트리 | ① 뿌리 질문 고르기 · ② 가지마다 다시 만들기(재귀) |

탭의 마지막 쪽에서 **[다음 →]**을 누르면 다음 알고리즘(그리고 정리)으로 이어집니다.

## 2. 시험 출제와 연결하기

중간고사의 8-퍼즐 문제("이 알고리즘으로 open에서 세 번째로 꺼낸 노드는?", "목표 상태는 몇 번째로 꺼내지는가?",
"찾은 경로의 이동 횟수는?")처럼, **알고리즘을 손으로 실행했을 때 자료구조의 n번째 상태**를 묻는 형식으로 맞췄습니다.
파이썬 코드는 사이트 어디에도 없습니다.

| 알고리즘 | 사이트가 만드는 문제 유형 (조건은 바뀜) |
|---|---|
| k-NN | 두 점 사이 d² · distances에 n번째로 추가되는 데이터 · **정렬 뒤 n번째로 가까운 데이터** · 투표가 끝난 votes 딕셔너리 · 예측 레이블 · k를 늘릴 때 예측이 처음 바뀌는 k |
| k-평균 | 1회차 점–중심 d² · 1회차 할당 뒤 묶음 A의 집 · 1회차 새 중심 좌표 · **몇 회차에 멈추는가** · 2회차에 묶음을 옮기는 집 · 최종 중심 |
| 선형회귀 | 첫 에폭 손실(MSE) · 첫 에폭 dw · 첫 갱신 뒤 w·b · 두 번째 에폭 손실이 커지나 작아지나 · 두 번째 에폭 예측값 |
| 의사결정트리 | 한 묶음의 지니/엔트로피 · 뿌리 특징 · **n번째로 만들어지는 노드** · 호출 스택의 최대 높이 · 함수 호출 횟수 · 새 날 예측 |

예제는 손으로 풀 수 있게 정수 좌표로 작게 잡았습니다.

- **k-NN**: 음식 9개 + 질문점 토마토(6, 4). d² = 오렌지 2, 견과류 5, 포도 8, 생선 10, 치즈 13, 당근 17, 오이 25, 사과 34, 셀러리 41 → k = 1·3 과일, k = 5·7 단백질. 연습용 질문점 6개는 모두 거리·투표 동점이 없습니다.
- **k-평균**: 집 6채, 기본 시작 중심 = 집1·집2. 1회차 새 중심 (5, 6.5)·(2, 2) → 2회차에 집1이 옮겨 (6, 7)·(2, 3) → 3회차에 수렴. 시작 중심 5가지(k = 3 포함)는 수렴까지 2~4회차.
- **선형회귀**: 공부 시간 1~5 → 점수 2, 4, 5, 7, 9. w = b = 0에서 첫 손실 35. 학습률 0.01(느림)·0.05(수렴)·0.1(발산).
- **의사결정트리**: 14일 축구 기록. 뿌리 지니 날씨 0.343 < 습도 0.367 < 바람 0.429 < 기온 0.440.

> 💡 **📝 추적표**는 그대로 빈칸 채우기 문제가 됩니다. 실제 시험은 학생이 연습한 조건과 다른 조건(다른 질문점·시작 중심·학습률)으로 내면,
> 외운 답이 아니라 절차를 따라가는지 확인할 수 있습니다.

## 3. 차시 예시 (3차시)

### 1차시 — 도구 + k-NN (45분)

| 시간 | 쪽 | 활동 |
|---|---|---|
| 0~5분 | 📦 안내 | 도구 카드의 "할 일 / 배우는 것 / 쓰이는 곳"을 읽어 주기 |
| 5~18분 | 📦 표 · 거리 · 정렬 · 딕셔너리 | 미션을 순서대로, 각 쪽의 "🔗 알고리즘 속에서는" 카드 하나씩 눌러 보기 |
| 18~35분 | 🤖 k-NN 문제 보기 → ①②③ | 예측 퀴즈를 반 전체가 손으로 답하고 ⏭ |
| 35~45분 | 🤖 k-NN 추적표 · 시험 대비 연습 | 추적표를 공책에 먼저 채우고 확인, 연습 5문제 |

### 2차시 — k-평균 + 선형회귀 (45분)

| 시간 | 쪽 | 활동 |
|---|---|---|
| 0~8분 | 📦 묶음·평균 · 갱신·기록 | 미션 진행 |
| 8~25분 | 🤖 k-평균 | 2회차에 집1이 묶음을 옮기는 장면에 주목, 추적표를 회차별로 채우기 |
| 25~43분 | 🤖 선형회귀 | 첫 에폭의 예측·오차·손실·dw·db를 손으로 계산 → 추적표로 확인, 학습률 비교 |
| 43~45분 | 정리 | "반복하며 값을 고치고, 바뀌지 않으면(또는 손실이 줄면) 멈춘다" |

### 3차시 — 의사결정트리 + 종합 (45분)

| 시간 | 쪽 | 활동 |
|---|---|---|
| 0~22분 | 🤖 의사결정트리 | 뿌리 점수표 손 계산, 호출 순서표(몇 번째로 만들어지는 노드인가) 채우기 |
| 22~27분 | ✅ 한 장 정리 | "데이터 이동" 칸을 짝과 번갈아 설명 |
| 27~45분 | ✅ 종합 모의시험 | 네 알고리즘 8문제, 틀린 문제는 "그 장면 보기" |

## 4. 알고리즘별 발문(질문) 포인트

| 알고리즘 | 멈추고 물어볼 장면 | 기대하는 대답 |
|---|---|---|
| k-NN | ② 정렬 직전 | "d²이 가장 작은 오렌지(2)가 0번" |
| k-NN | 추적표 k = 5 | "4·5번째 이웃(생선·치즈)이 단백질이라 표가 뒤집혔다" |
| k-평균 | ③ 2회차 묶음 비우기 | "지난번 묶음을 버리고 모두 대기 줄로 — 처음부터 다시 나눈다" |
| k-평균 | 수렴 판정 줄 | "묶음이 그대로면 평균도 그대로 → 멈춘다" |
| 선형회귀 | ③ 갱신 직전 | "dw가 음수니 빼면 w가 커진다" |
| 선형회귀 | 추적표 lr = 0.1 | "손실 기록이 커지기만 한다 → 발산" |
| 의사결정트리 | ① 고르기 줄 | "가장 **작은** 점수 — 불순도는 섞인 정도" |
| 의사결정트리 | ② 재귀 호출 | "가지마다 함수를 다시 부르면 스택에 쌓이고, 끝나면 빠진다" |

> 💡 8-퍼즐 사이트를 함께 배운 반이라면: "트리 만들기의 호출 스택 = 8-퍼즐 DFS의 스택"을 이어 주세요.

## 6. 자주 묻는 것

- **파이썬을 몰라도 되나요?** — 네. 사이트에는 의사코드만 있습니다.
- **자동 재생이 중간에 멈춰요.** — 🔮 예측 퀴즈 앞에서 기다리는 것입니다. 실행 제어 막대의 **🔮 예측 퀴즈** 체크를 끄면 멈추지 않습니다.
- **글씨가 작아요.** — 오른쪽 위 **가＋**. 화면이 좁으면(태블릿·휴대폰) 세로 한 줄로 접힙니다.
- **처음 상태로 돌리고 싶어요.** — 쪽 위치·조건·미션 진행이 브라우저에 저장됩니다. 도구 쪽은 **↺ 처음으로**, 추적표는 조건을 기본값으로 돌리거나, 브라우저의 사이트 데이터를 지우면 처음으로 돌아갑니다.

## 7. 과제 아이디어

1. k-NN 연습용 질문점(파프리카·자두·두부·감자·망고) 하나를 골라 거리 추적표와 k별 예측을 손으로 채우기.
2. k-평균 시작 중심을 바꿔 가며 **수렴까지 몇 회차가 걸리는지** 표로 정리하고, 최종 묶음이 같은지 비교하기.
3. 선형회귀 학습률 0.01·0.05·0.1의 손실 기록 모양을 비교해 표로 정리하기.
4. 의사결정트리 최대 깊이 1과 기본 트리의 **학습 데이터 정확도**(10/14 vs 14/14)를 비교하고 과대적합과 연결하기.
5. 시험 대비 연습에서 틀린 문제 하나를 골라, 그 장면의 자료구조 상자를 그려 오답 노트 만들기.
