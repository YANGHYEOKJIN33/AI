# 교사용 안내 — 자료구조로 다시 보는 머신러닝

학생들이 **k-최근접 이웃 · k-평균 · 선형회귀 · 의사결정트리**를 이미 한 번 배운 뒤,
"공식"이 아니라 **"데이터가 어떤 자료구조로 옮겨 가는가"**로 다시 설명할 수 있게 만드는 복습용 사이트입니다.
설치·로그인 없이 주소 하나로 접속합니다.

> 사이트 주소: `https://yanghyeokjin33.github.io/Fundamentals-of-AI/`

---

## 1. 화면 구조

| 큰 탭 | 쪽 | 무엇을 |
|---|---|---|
| **📦 자료구조 도구** | 7쪽 | 네 알고리즘이 함께 쓰는 도구를 손으로 조작 (첫 화면) |
| **🤖 알고리즘** | 4 × 3쪽 | `[k-최근접 이웃] [k-평균 군집] [선형회귀] [의사결정트리]` 하위 탭 |
| **✅ 정리·확인** | 2쪽 | 한 장 정리표 + 이해 확인 10문제 |

알고리즘마다 **똑같은 3쪽**으로 복습합니다.

> ① **한눈에 복습** — 복습 카드(문제 유형·입력→출력·절차 4단계·쓰는 도구·기억할 점). ▶ 재생하면 지금 단계에 불이 켜지고, 끝나면 **써 보기**
> ② **의사코드로 한 단계씩** — ⏭ 한 단계마다 그 줄이 바꾼 자료구조가 빛나고, 데이터가 상자 사이를 미끄러져 이동
> ③ **의사코드 ↔ 파이썬** — 같은 줄을 나란히, **🔑 핵심 한 줄**을 바꿔 결과 비교

탭의 마지막 쪽에서 **[다음 →]**을 누르면 다음 알고리즘(그리고 정리)으로 이어집니다.

## 2. 차시 예시 (2~3차시)

### 1차시 — 도구 다시 잡기 + k-NN (45분)

| 시간 | 쪽 | 활동 |
|---|---|---|
| 0~5분 | 📦 1. 복습 지도 | 네 카드의 "데이터 이동"을 읽고 "오늘은 이 화살표들을 따라간다"고 안내 |
| 5~12분 | 📦 2. 표 · 3. 거리 | `data[i][j]` 짚기, 거리 한 단계씩, 거리 리스트 채우기 |
| 12~20분 | 📦 4. 정렬·[:k] · 5. 딕셔너리 | sort 전에 맨 앞 맞히기, `[:k]` 복사, 토큰 세기와 max |
| 20~40분 | 🤖 k-NN ①②③ | ②에서 예측 퀴즈를 반 전체가 손으로 답하고 ⏭, ③에서 k = 1·3·5·7 |
| 40~45분 | 정리 | "k-NN = 표 → distances → sort → [:k] → votes → max"를 말로 |

### 2차시 — k-평균 + 선형회귀 (45분)

| 시간 | 쪽 | 활동 |
|---|---|---|
| 0~8분 | 📦 6. 묶음·평균 · 7. 갱신·기록 | 규칙 두 가지로 나눠 보고, 학습률 1.05로 공이 튕겨 나가는 것 보기 |
| 8~25분 | 🤖 k-평균 ①②③ | 2회차에 묶음이 바뀌는 점(점선 칩)에 주목, ③ "나쁜 시작" |
| 25~43분 | 🤖 선형회귀 ①②③ | 열이 위→아래로 채워짐, `dw` 부호와 w 변화, ③ 학습률 0.01·0.05·0.1 |
| 43~45분 | 정리 | "반복하며 값을 고치고, 바뀌지 않으면(또는 손실이 줄면) 멈춘다" |

### 3차시 — 의사결정트리 + 정리 (45분)

| 시간 | 쪽 | 활동 |
|---|---|---|
| 0~25분 | 🤖 의사결정트리 ①②③ | 특징마다 행이 묶음으로 이동, 점수표 최소, **호출 스택**이 쌓였다 빠짐 |
| 25~32분 | ✅ 1. 한 장 정리 | 표의 "데이터 이동" 칸을 짝과 번갈아 설명 |
| 32~45분 | ✅ 2. 이해 확인 | 10문제, 틀린 문제는 "다시 밟아 보기"로 그 장면 확인 |

## 3. 알고리즘별 발문(질문) 포인트

| 알고리즘 | 멈추고 물어볼 장면 | 기대하는 대답 |
|---|---|---|
| k-NN | 5줄(정렬) 직전 | "거리가 가장 작은 오렌지가 0번" — 튜플은 첫 값으로 비교 |
| k-NN | ③ k = 5 | "4·5번째 이웃(생선·베이컨)이 단백질이라 표가 뒤집혔다" |
| k-평균 | 2회차 3줄(묶음 비우기) | "지난번 묶음을 버리고 모두 대기 줄로 — 처음부터 다시 나눈다" |
| k-평균 | 8줄(수렴 판정) | "묶음이 그대로면 평균도 그대로 → 멈춘다" |
| k-평균 | ③ 나쁜 시작 | "중심 두 개가 같은 동네에 있어 그 동네를 쪼갠 채 굳었다(지역 최적)" |
| 선형회귀 | 7줄(갱신) 직전 | "dw가 음수니 빼면 w가 커진다" |
| 선형회귀 | ③ lr = 0.1 | "history가 커지기만 한다 → 발산" |
| 의사결정트리 | 7줄(고르기) | "가장 **작은** 점수 — 불순도는 섞인 정도" |
| 의사결정트리 | 9·10줄 | "가지마다 함수를 다시 부르면 스택에 쌓이고, 끝나면 빠진다" |

> 💡 8-퍼즐 사이트를 함께 배운 반이라면: "트리 만들기의 호출 스택 = 8-퍼즐 DFS의 스택"을 이어 주세요.

## 4. 색과 모양의 뜻

| 표시 | 뜻 |
|---|---|
| 파랑 테두리·배경 | 지금 실행 중인 줄 / 지금 다루는 데이터 |

| ●▲■◆✖ | 레이블·묶음 (색과 함께 모양으로도 구분) |

## 5. 자주 묻는 것

- **파이썬을 몰라도 되나요?** — 타이핑은 하지 않습니다. ③쪽에서 의사코드와 같은 줄의 파이썬을 *읽고*, 핵심 한 줄만 드롭다운으로 바꿉니다.
- **자동 재생이 중간에 멈춰요.** — 🔮 예측 퀴즈 앞에서 기다리는 것입니다. 실행 제어 막대의 **🔮 예측 퀴즈** 체크를 끄면 멈추지 않습니다.
- **글씨가 작아요.** — 오른쪽 위 **가＋**. 화면이 좁으면(태블릿·휴대폰) 세로 한 줄로 접힙니다.
- **처음 상태로 돌리고 싶어요.** — 브라우저에 설정(쪽 위치·핵심 한 줄)이 저장됩니다. ③쪽에서 핵심 한 줄을 기본값으로 돌리거나, 브라우저의 사이트 데이터를 지우면 처음으로 돌아갑니다.

## 6. 과제 아이디어

1. k-NN ①쪽에서 질문점을 옮겨 가며 **분류가 바뀌는 경계**를 찾아 그림으로 그리기.
2. k-평균 "나쁜 시작"과 기본 시작의 묶음을 비교하고, **왜 나쁜 시작이 고쳐지지 않는지** 3문장으로 설명하기.
3. 선형회귀 학습률 0.01·0.05·0.1의 손실 기록(history) 모양을 비교해 표로 정리하기.
4. 의사결정트리 ③쪽에서 최대 깊이 1과 기본 트리의 **학습 데이터 정확도**(10/14 vs 14/14)를 비교하고 과대적합과 연결하기.
5. "도구 × 알고리즘" 표에 없는 알고리즘(예: 나이브 베이즈) 하나를 골라, 어떤 도구를 쓸지 예상해 보기.
