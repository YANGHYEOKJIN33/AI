# 자료구조로 다시 보는 머신러닝 알고리즘

이미 배운 **k-최근접 이웃 · k-평균 · 선형회귀 · 의사결정트리**를
의사코드 한 줄마다 **데이터가 어느 자료구조에서 어느 자료구조로 옮겨 가는지** 눈으로 따라가며
복습하는 고등학생용 웹 학습 사이트입니다.

[8-퍼즐 탐색 사이트](https://yanghyeokjin33.github.io/8puzzle/)와 같은 구조·화면 언어로 만들었습니다.
8-퍼즐 사이트가 "OPEN이 큐냐 스택이냐가 탐색을 정한다"를 보여 줬듯, 이 사이트는
**"어떤 자료구조로 데이터를 옮기느냐가 학습 알고리즘의 절차다"**를 보여 줍니다.

```
https://yanghyeokjin33.github.io/Fundamentals-of-AI/
```

> `main` 브랜치에 병합되면 GitHub Actions가 자동으로 게시합니다 → [docs/DEPLOY.md](./docs/DEPLOY.md)

## 무엇을 복습하나요

| 알고리즘 | 문제 | 데이터 이동 (의사코드를 밟으면 이렇게 움직여요) |
|---|---|---|
| 📍 k-최근접 이웃 | 분류 · 지도 | 표 ➜ `distances`(리스트에 append) ➜ `sort` ➜ `[:k]` ➜ `votes`(딕셔너리) ➜ `max` |
| 🎯 k-평균 군집 | 군집 · 비지도 | 대기 줄 ➜ `clusters[c]`(묶음 리스트로 이동) ➜ 평균 ➜ `new` ➜ `centroids` 교체 (반복) |
| 📈 선형회귀 | 회귀 · 지도 | `X` ➜ `pred`·`err` 리스트 ➜ 평균 ➜ `loss`·`dw`·`db` 변수 ➜ `w`·`b` 갱신 ➜ `history.append` |
| 🌳 의사결정트리 | 분류 · 지도 | `rows` ➜ `groups`(값별 묶음) ➜ 레이블 세기 ➜ `score` 딕셔너리 ➜ `min` ➜ `build()` 재귀 = 호출 스택 |

예제 데이터는 **시험에서 손으로 풀 수 있는 크기**로 골랐습니다 — 토마토 분류(음식 9개, 좌표는 정수),
배달 거점(집 6채), 공부 시간 → 점수(5명), 축구할까?(14일 기록, 교과서의 테니스 예제).
거리는 비교만 하면 되므로 √ 없이 **거리의 제곱 d²**(정수)으로 계산합니다.

## 화면 구성 — 큰 탭 셋

| 큰 탭 | 쪽 | 무엇을 |
|---|---|---|
| **📦 자료구조 도구** (첫 화면) | 7쪽 | 안내 + 표 · 거리 · 정렬과 앞에서 k개 · 딕셔너리 세기 · 묶음과 평균 · 갱신과 기록. 쪽마다 **🎯 미션**(할 일 순서, 다음 단추가 깜빡임) → **🎓 배운 것** → **🔗 알고리즘 속에서는**(그 도구가 쓰이는 장면으로 바로 이동) |
| **🤖 알고리즘** | 4 × 5~6쪽 | 하위 탭마다 **문제 보기 → 단계 쪽 2~3개 → 📝 추적표로 정리 → 🎯 시험 대비 연습** |
| **✅ 정리·확인** | 3쪽 | 한 장 정리표 · 종합 모의시험(네 알고리즘 섞어서) · 개념 확인 |

알고리즘의 **단계 쪽**은 의사코드 일부(예: k-NN ② 정렬하고 k개 고르기 = 5~6줄)만 다루고,
그 단계에서 바뀌는 자료구조 상자만 보여 줍니다. 한 쪽에서 볼 것을 줄여 시선이 한곳에 머물게 했습니다.

```
┌ 의사코드 (이 쪽의 줄만 진하게) ┐┌ 그림(산점도·트리) + 계산 상자 ───────┐
│ 지금 줄 강조 + 그 줄의 설명     ││ 점·중심·직선이 미끄러져 움직임         │
│                                 │├────────────────────────────────────────┤
│                                 ││ 이 단계의 자료구조 상자만 — 바뀐 상자가 │
│                                 ││ 빛나고 데이터가 상자 사이로 이동(복사)  │
└─────────────────────────────────┘└────────────────────────────────────────┘
```

- **실행 제어**(단계 쪽에서만): ⏹ 처음으로 · ⏮ 뒤로 · ▶ 재생 · ⏭ 한 단계 · ⏭⏭ 다음 반복 · ⏩ 끝까지 (키보드 `Space` `→` `←` `Home` `End` `PageDown`). 쪽 범위 안에서만 움직입니다.
- **🔮 예측 퀴즈**: "정렬하면 맨 앞은?", "이 집은 어느 묶음?", "w는 커질까?" — 자동 재생은 퀴즈 앞에서 기다립니다
- **📝 추적표**: 시험 답안처럼 단계마다 자료구조 값을 적은 표. 칸이 **?**로 가려져 있어 손으로 채운 뒤 눌러서 확인합니다. 조건(k · 시작 중심 · 학습률 · 지니/엔트로피 · 최대 깊이)을 바꾸면 표가 다시 계산됩니다.
- **🎯 시험 대비 연습**: 중간고사 8-퍼즐 문제("open에서 세 번째로 꺼낸 노드는?")와 같은 형식의 객관식이 조건을 바꿔 가며 자동으로 만들어집니다 — 예: "distances를 정렬했을 때 세 번째로 가까운 데이터는?", "몇 번째 회차에서 멈추는가?", "첫 에폭 갱신 뒤 w는?", "두 번째로 만들어지는 질문 노드는?". 채점 뒤 **🔎 그 장면 보기**로 정답이 나오는 장면으로 바로 갑니다.
- **📖 용어 사전 · ⓘ 용어 풍선**, 다크 모드, 글자 크기, 첫 방문 안내

> 시험에 파이썬 코드는 내지 않으므로, 사이트에도 파이썬 코드는 없습니다. 모든 설명은 의사코드 기준입니다.
